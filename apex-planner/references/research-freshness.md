# Research Freshness

Facts expire at different rates.

Classify findings:
- stable: language semantics, mature architecture principles;
- medium-volatility: framework guidance, supported versions, cloud behavior;
- high-volatility: current model/tool features, pricing, quotas, releases, security advisories.

Record research date, version applicability, and freshness window. Re-check high-volatility findings immediately before final handoff.

Never treat a search snippet as sufficient evidence for a consequential design decision.
