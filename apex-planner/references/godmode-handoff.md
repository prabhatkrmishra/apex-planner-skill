# Godmode Handoff

At completion, reference the existing `apex-godmode` skill by canonical name. Do not copy its implementation instructions.

Handoff fields:
- plan artifact
- goal
- selected approach
- scope
- constraints/non-goals/invariants
- mandatory research findings
- verification matrix
- migration/rollback requirements
- critical risks
- open decisions

Godmode must re-check assumptions before editing. If repository reality contradicts the plan, it should stop and re-plan rather than silently implementing stale assumptions.
