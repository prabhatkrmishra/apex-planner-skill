# Plan Diff and Resume Semantics

When revising an existing plan:
- preserve stable requirement, decision, risk, and step IDs;
- record what changed and why;
- identify invalidated assumptions and research;
- revalidate downstream dependencies;
- avoid silently changing scope.

When resuming an interrupted planning session:
- reconstruct current repository state;
- verify prior evidence is still fresh;
- mark stale research/evidence explicitly;
- continue from the last valid phase, not from an assumed state.
